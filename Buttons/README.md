# Buttons

Here are two versions of some more accessible button formats. Simply 5mm raised with a -20 degree taper. I added the maximum chamfer and fillet to the corners that I could manage. Fillet is 45% corner, a little more ideal for FDM printing, fillet is rounded edge, looks better on balance. 
Any other simple requests let me know!
